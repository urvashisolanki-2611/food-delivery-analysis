# Food Delivery Analysis

## Project Overview
This project analyzes food delivery data to understand order trends, customer preferences, and business performance.

## Objectives
- Analyze food delivery orders.
- Identify popular food items and ordering patterns.
- Understand sales and delivery trends.
- Present meaningful insights to support business decisions.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Charts and Data Visualization

## Project Files
- Food Delivery Analysis Excel workbook
- Food Delivery Insights Word report
